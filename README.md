## Sobre mí

Desarrollo software a medida: aplicaciones web, CRM, comercio electrónico y sistemas para el sector salud. Construyo de punta a punta (API, base de datos e interfaz) y reviso cada sistema también desde el riesgo: credenciales, permisos y datos sensibles. Soy Ingeniero de Sistemas y Especialista en Seguridad de la Información.

## Tecnologías

<p align="center">
  <img src="https://skillicons.dev/icons?i=cs,dotnet,react,vue,nuxtjs,ts,postgres,powershell,git,vercel&perline=10" alt="C#, .NET, React, Vue, Nuxt, TypeScript, PostgreSQL, PowerShell, Git y Vercel" />
</p>

- **Backend:** C#, .NET / ASP.NET Core, Entity Framework Core, APIs REST, autenticación con JWT
- **Frontend:** React, Vue 3 con Pinia, Nuxt, Blazor, TypeScript
- **Datos:** SQL Server, PostgreSQL
- **Scripting y pruebas:** PowerShell, xUnit, Pester
- **Seguridad:** autenticación y autorización, aislamiento de datos entre clientes (multi-tenant), manejo de secretos, validación de firmas en webhooks
